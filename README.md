# DEEROCK — A Frontend Developer's Ordinary Days

A slice-of-life workplace comic about Deerock, a frontend developer, and a small software team.

## Canon
- Genre: slice of life, workplace comedy, light drama, wholesome
- Setting: modern Jakarta software company
- Main cast: Deerock (FE), Aki (UI/UX), Kai (BE), Rin (QA), Mika (PM)
- No katana, ninja, supernatural, or action-fantasy elements.
- Episode 01 starts at home, continues through KRL commute, then the office.
- Trailer is the visual/tonal reference for the project.

## Production rule
Do not invent or alter canonical character traits without updating the relevant bible first.

## Workflow
1. Read `AGENTS.md`.
2. Read the relevant bible files.
3. Read the episode brief/storyboard.
4. Check reference assets before generating art.
5. Generate one panel/scene at a time when consistency matters.
6. Review against the consistency guide.
7. Only then assemble the final page.

See `bible/consistency-guide.md` for the full visual continuity system.
