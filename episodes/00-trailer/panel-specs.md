# DEEROCK — Trailer Panel Specifications

## Scope and production guardrails

- **Source storyboard:** `episodes/00-trailer/storyboard.md`. This specification expands that storyboard only; it does not add scenes, change dialogue, or alter character canon.
- **Artwork status:** No artwork is requested or generated by this document. The file IDs below are reserved production names for a future panel-by-panel workflow.
- **Format:** Three vertically read pages, 10 panels total (Page 1: 01–03; Page 2: 04–07; Page 3: 08–10).
- **Visual treatment:** Contemporary manga/anime slice-of-life; clean linework, restrained cel shading, subtle halftone/texture, soft cinematic lighting, and realistic modern Indonesian environments. Do **not** use a photorealistic rendering treatment.
- **Text treatment:** Indonesian spoken dialogue; English only for necessary common technical terms, UI terms, and signage already present in the reference. Do not add motivational/inspirational copy, positive decorative text, random captions, or decorative reference-sheet slogans. Allowed text is only the specified dialogue, functional UI, necessary signage, the final episode label, and SFX.
- **Hard exclusions:** No fantasy, ninja, katana, samurai, tactical costume, supernatural effects, action aura, glowing weapon, cyberpunk transformation, or exaggerated action staging.
- **Panel production method:** Generate/review one panel at a time against the named reference sheets. If identity or environment geometry drifts, revise from the reference; do not accept drift or redesign the asset.
