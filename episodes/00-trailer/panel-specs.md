# DEEROCK — Trailer Panel Specifications

## Scope and production guardrails

- **Source storyboard:** `episodes/00-trailer/storyboard.md`. This specification expands that storyboard only; it does not add scenes, change dialogue, or alter story/canon.
- **Format:** ONE vertical 9:16 page, 10 panels total, read continuously top-to-bottom. No separate trailer pages.
- **Artwork status:** No artwork is requested or generated by this document. File IDs below remain reserved production names for panel-by-panel workflow.
- **Visual treatment:** Contemporary manga/anime slice-of-life; clean linework, restrained cel shading, subtle halftone/texture, soft cinematic lighting, realistic modern Indonesian environments. Do not use photorealistic rendering.
- **Text treatment:** Indonesian spoken dialogue; English only for necessary common technical terms, UI terms, and existing signage. No motivational/inspirational copy, random captions, decorative slogans, or invented screen text. Allowed text is specified dialogue, functional UI/signage, SFX, and the final episode label plus `COMING SOON`.
- **Hard exclusions:** No fantasy, ninja, katana, samurai, tactical costume, supernatural effects, action aura, glowing weapon, cyberpunk transformation, or exaggerated action staging.
- **Panel production method:** Generate/review one panel at a time against named references. If identity or environment geometry drifts, revise from reference; do not accept drift or redesign approved assets.
