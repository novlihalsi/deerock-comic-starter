# Off-canon references — read before using anything in this folder

Images in this folder are **not** production references. They exist because they contain one
useful piece of information surrounded by material that breaks canon.

## Rule

Never pass a file from this folder as a plain "character reference". If you pass it at all,
the prompt must name the one thing you are taking from it and explicitly reject the rest.

## `deerock-virelux-cover.png`

- **Take:** Deerock's face geometry, eye shape, glasses proportion, hair silhouette in a
  three-quarter rear turn.
- **Reject:** the katana, the tactical harness/straps/buckles, the magazine typography, the
  heavy purple duotone grade, the "VIRELUX" branding, and the dramatic hero framing.
- **Preferred alternative:** `characters/deerock.png` already carries a front, 3/4, side and
  back turnaround plus six expressions. Use that first. Only reach for this file if the
  approved sheet genuinely does not cover the angle you need.

This file used to sit in `characters/` as `deerock-additional-face-ref-1.png`. Every agent
instruction in this repo says "inspect the character's reference images before generating",
so leaving it there meant a katana and tactical armour were being fed into a comic whose
canon forbids both.
